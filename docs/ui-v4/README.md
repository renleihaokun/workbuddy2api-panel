# 面板视觉与交互 v4

> **文档性质**：历史视觉 / 交互归档（快照），不等同于当前面板规范。当前行为以 `internal/panel/*` 与根 README 为准。

本轮不是换皮，而是把「实际在用的生产面板」按真实窗口尺寸走了一遍，优先修
**看不见关键信息、点不到操作、页面被撑到几万像素**的问题。设计语言、色板、
字体令牌和 CSP 均未改；仍然没有前端构建步骤。

## 范围与结论

- 实测窗口：1440×900、1024×768、768×1024、390×844、320×568。
- 主要问题不是配色，而是**响应式断点错位**与**一次渲染太多 DOM**：
  - 760px 以下才切手机布局，导致 768/1024 仍用桌面表格，操作列被推到屏外；
  - 首页「积分到期提醒」默认展开，19 个账号时把账号池推到第二屏；
  - 积分构成按账号全量铺明细，页面随账号数线性增长；
  - 运行日志把上千行一次性塞进 DOM，手机上要滚很久；
  - 用量图固定 1200 宽 viewBox，在 1024/768 被整体缩小，手机 x 轴只写
    `HH:00`，跨天时看起来像时间倒序。

## 断点与布局

| 宽度 | 壳层 | 账号/模型/请求 | 统计卡 |
| --- | --- | --- | --- |
| ≤700 | 抽屉 + 卡片 | 卡片，单列/双列自适应 | 2 列，最后一张通栏紧凑 |
| 701–1000 | 抽屉 + 卡片 | 卡片 | 3 列 |
| 1001–1150 | 侧栏 + 表格 | 表格；收起「用量」列 | 4 列 |
| 1151–1599 | 侧栏 + 表格 | 全列 | 4 列 |
| ≥1600 | 侧栏 + 表格 | 全列 | 7 列 |

手机/平板断点从 760 统一到 **1000**；`mobile.js` 的 `MOBILE_MQ`、日志页签
的 `matchMedia`、`mobile.css` 的媒体查询三处保持一致。1001 起才恢复侧栏与
表格，避免 768/1024 出现「桌面壳 + 挤爆的表格」。

## 具体改动

### 1. 首屏与信息密度

- 积分到期提醒：
  - 账号数 >8 且用户没有显式选择时默认折叠；
  - 卡片头始终保留「最近到期 / 7 天内合计 / 账号数」摘要和「展开 / 收起明细」「刷新明细」；
  - 用户点过一次后写入 `wb2api.expfold.v1`，之后按用户选择，不再自动改。
- 统计卡：
  - 可用卡补「可用率」；
  - 积分卡补「剩余 % · 已用」；
  - 手机端最后一张「粘性会话」通栏紧凑显示，不再独占一整块空白。
- 积分构成：
  - 账号摘要卡变成明细选择器（点击/回车切换），只渲染当前账号的逐包表；
  - 顶部保留账号下拉，键盘也能操作；
  - 到期分布只给前 8 个账号上色，其余用灰色「其他 N 个账号」，避免 12 色循环造成假分组；
  - 条长按该档积分合计计算，90 天以上的桶折叠并在脚注给出总量。

### 2. 账号与导航

- 账号名消歧：重名追加 uid 前 4 位；长邮箱缩短域名保留 `@…`；窄屏下长名字保留尾部区分位，宽屏（≥1600）显示全名。
- 账号表：
  - 操作列 sticky；1024 宽度下收起「用量」并把账号/状态列收窄，表格不再横向溢出；
  - 表头补 `scope`，操作列表头用 `.sr-only` 文本，修复 `td-has-header`。
- 导航：
  - 视图切换写入 `history.pushState`，浏览器后退/前进可在面板视图间切换；
  - 每次切换 `scrollTo(0,0)`，避免从长页切到短页时停在页底；
  - `document.title` 跟随视图更新。

### 3. 图表

- 新增 `chartWidth(host, fallback, min, max)`：宽度跟容器，隐藏视图回退。
- 新增 `niceStep` / `fmtTokTick`：y 轴取整刻度（`750k`、`500k`、`250k`），不再出现
  `670.2k` 这种非整刻度。
- 新增 `fmtAxisTimeLabel`：跨天或跨度 >20h 时显示 `MM-DD HH:00`，同一天内才只写
  `HH:00`；日桶显示 `MM-DD`。
- 用量、积分走势、通道趋势/失败率都改为容器宽度；手机 x 轴按宽度取 2–4 个刻度，390 宽只保留首尾，避免日期标签互相压住。
- 修 `数据自 2026-10-14 20` 缺分钟的问题（13 位小时串补 `:00`）。

### 4. 日志、请求、模型

- 运行日志在 ≤1000 用「请求记录 / 服务日志 / 积分历史」页签，一次只显示一块；
  `#logBox` 改为三列网格（时间 / 频道 / 正文），频道 chip 与时间同行。
- 请求记录手机端首屏 20 条 + 「加载更多 20 条」，账号卡隐藏 IP / UA / 请求 ID；
- 模型页手机端首屏 20 个 + 「显示更多」，模型 ID 允许两行，`effort` 下拉不再盖住箭头；
- 桌面端仍一次显示全部，不改变原有桌面行为。

### 5. 配置与任务

- 配置表单加载完成后不显示保存条；只有用户真正改过字段才显示「已修改 N 项」。
  dirty 判定用回填后的表单快照，不把 HTML 默认值算成修改。
- 有未保存修改时刷新/关闭页面会触发 `beforeunload`；「放弃修改」二次确认。
- 任务中心队列为空时「执行选中」禁用，避免点了没反应。

## 验证

- `node --check internal/panel/app.js`
- `node --check internal/panel/mobile.js`
- `go test ./internal/panel`（含前端 harness、折叠、图表刻度、账号名、CSS 字号下限等）
- 生产面板 Lighthouse（1440 桌面与 390 手机）：Accessibility / Best Practices / SEO / Agentic Browsing 均为 100，0 项失败。
- 320/390/768/1000/1001/1024/1440/1920 逐档检查横向溢出与首屏可见性；1001 起表格无横向滚动。

## 明确没做的事

- 没有新增色板、字体或图标库；没有引入构建链。
- 没有改 API、状态文件格式或 CSP。
- 没有把桌面 >1150 的视觉语言推倒重来；桌面宽屏的表格与卡片仍保持原结构。
- 没有读取或写入任何账号凭据；本地预览使用的是合成数据。
