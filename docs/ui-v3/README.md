# UI v3 视觉归档（v1.20.0-panel）

> **文档性质**：历史视觉 / 交互归档（快照），不等同于当前面板规范。当前行为以 `internal/panel/*` 与根 README 为准。

由本地 fixture 页面（`mock` 数据，不含真实账号/密钥）渲染，用于对比改动前后的视觉状态。

| 文件 | 内容 |
|---|---|
| `accounts-1440-dark.webp` | 账号池 1440×900 深色：列宽预算后操作列完整可见、限流芯片不再撑高行 |
| `accounts-1024-scrollhint.webp` | 1024×768 窄桌面档：表格上方显示「左右滑动查看全部列 →」提示 |
| `select-popup-light.webp` | 模型筛选「全部能力」自绘候选层（浅色）：玻璃浮层、勾选态、无系统蓝 |
| `select-sheet-mobile.webp` | 390×844 手机上同一控件的底部 sheet：拖拽条、56px 行高、勾选态 |

补充说明：

- 原生 `<select>` 仍是值/语义来源，自绘层只是视觉镜像；截图中的展开层是 DOM 元素，因此可以被截图与自动化检查（系统弹层拍不到，这正是此前审计漏检的原因）。
- 三个视图都启用了新的账号表列宽预算与手机卡片重排；`docs/ui-v2/` 保留改动前的 v1.19 基线，便于对照。
